## 🛠️ 技術実績・実装内容（2026-06-02 時点）

本プロジェクトは、短期間での開発環境構築から、フロントエンド、バックエンド、およびクラウドインフラへの実戦配備にいたるWebシステム開発の全工程を、段階的かつ最速で検証・実装した記録である。

### 1. フロントエンド（非同期通信の統合）
- **Fetch APIのスクラッチ実装**: 従来の画面全体のリロード（HTTPリクエストによる画面遷移）を排除し、`Fetch API` を用いた非同期データ送信（CRUD機能・削除機能）を実装。ユーザーの操作性を大幅に向上。

### 2. バックエンド（MVCアーキテクチャの構築）
- **Rails 8による基盤構築**: Ruby on Rails 8のMVC（Model-View-Controller）思想およびマイグレーションの仕組みを深く理解し、破綻のないデータベース設計を短期間で構築。

### 3. インフラ・デプロイ環境の制約回避
- **ローカル・プリコンパイルの導入**: クラウドインフラ（Render）の無料枠における「512MB RAM制限」によるビルドエラーを回避するため、アセット（資産）をローカル環境で事前にコンパイルしてデプロイする手法を確立。
- **永続ストレージ（storage/）マウント**: サーバー再起動時にデータが初期化される「Read-only file system」の制約に対し、SQLite3のデータベースファイルを特定の永続ディレクトリ（`storage/`）へバインド（配備）することで、データの永続化に成功。

### 4. 構成管理・デプロイ運用
- **Git/GitHubを用いたソースコード管理**: 複数環境での競合（トラブル）をGitリベースによって統合・解消し、クリーンなコミット履歴を維持した状態での「世界出荷（本番デプロイ）」を完遂。
